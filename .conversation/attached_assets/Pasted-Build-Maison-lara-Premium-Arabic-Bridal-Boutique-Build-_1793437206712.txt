Build Maison Élara — Premium Arabic Bridal Boutique

Build an exceptionally premium, mobile-first Arabic RTL wedding dress ecommerce website for a fictional luxury bridal boutique in Syria called Maison Élara | ميزون إيلارا.

This is a frontend-only prototype intended to demonstrate the product to a potential real-world client. The website must look and feel like an expensive, professionally designed luxury fashion brand, not a generic ecommerce template.

1. Technology and architecture

- React + TypeScript + Vite.
- Tailwind CSS.
- Framer Motion for refined animations.
- Lucide React for icons.
- Use reusable components and a clean, scalable architecture.
- Use local mock data for dresses, appointments, testimonials, and categories.
- Use localStorage for wishlist and demo booking persistence.
- No Supabase.
- No backend.
- No authentication service.
- No external APIs.
- No real payment processing.
- No unnecessary dependencies.

Build a frontend that can later be connected to Supabase and converted into a PWA or mobile application without rebuilding the entire interface.

2. Design direction

The visual experience must feel like a luxury bridal fashion house.

Design references:

- High-end fashion editorial websites.
- Luxury bridal boutiques.
- Premium fashion magazines.
- Minimalist Apple-like UI craftsmanship.

Color palette:

- Warm ivory: #F8F5F0
- Champagne: #E9D5BE
- Antique gold: #B58A55
- Deep charcoal: #29231F
- Muted taupe: #A58C78

Typography:

- Elegant Arabic typography.
- Use a refined Arabic serif or display font for headings.
- Use a highly readable Arabic font for body text.
- Use a sophisticated Latin serif for the Maison Élara brand name.

Use generous whitespace, refined borders, subtle shadows, cinematic photography, and elegant transitions.

Avoid:

- Generic ecommerce templates.
- Excessive rounded cards.
- Bright colors.
- Excessive gradients.
- Overly playful animations.
- Dense layouts.
- English interface text.

3. Arabic and RTL

The entire customer-facing website must be in Arabic.

Use:

- Arabic RTL layout.
- Correct RTL navigation.
- Arabic product descriptions.
- Arabic form labels and validation.
- Arabic booking calendar.
- Arabic testimonials.
- Arabic buttons and notifications.

Set the document direction to RTL globally.

Use Arabic numerals consistently where appropriate.

The fictional boutique is located in Syria. Use Syrian context, Syrian pounds (ل.س) for displayed demo prices, and realistic Syrian phone number formatting.

The Maison Élara brand name can remain in Latin characters alongside its Arabic identity.

4. Mobile-first experience

The mobile version is the primary design target.

Design for a 390px-wide mobile viewport first, then expand beautifully to tablets and desktops.

Requirements:

- App-like mobile navigation.
- Fixed bottom navigation bar.
- Large touch-friendly controls.
- Smooth mobile transitions.
- Full-screen mobile product galleries.
- Bottom sheets for filters and selection dialogs where appropriate.
- Mobile-friendly booking calendar.
- Safe-area support for modern mobile devices.
- No horizontal overflow.
- Fast-feeling interactions.

On desktop, expand into a premium editorial layout with spacious galleries and refined navigation.

Structure the code so it can later become a PWA or mobile app.

8. Dress reservation experience

A customer should be able to:

1. Select a dress.
2. Choose a size.
3. Select a preferred reservation date.
4. Enter her name.
5. Enter her Syrian phone number.
6. Add an optional note.

Clearly indicate that this is a demo reservation and no real booking is transmitted.
